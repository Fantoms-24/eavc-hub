Фон приложения
================

Положите сюда файл app-bg.png (рекомендуется 1920×1080 или шире, JPG/PNG/WebP).

Текущий путь в CSS: static/css/app.css → --wp-app-bg-image

Чтобы заменить фон: перезапишите app-bg.png и обновите страницу (Ctrl+F5).

Страница входа (/login) использует свой анимированный фон и этот файл не подключает.
