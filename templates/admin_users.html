              Ручная архивация сеансов
            

            

              Оставляет в таблице seanses только выбранный день, все остальные записи переносит в архив.
              Подразделения (unit), перехваты и справочники не затрагиваются.
            

          

          

            
            
          

        

        

          

            
            
          

          

            

              Если дату не указывать, будет взят текущий день компьютера. Операция необратима.
              Кнопка «Все сеансы в архив» переносит каждую строку из seanses в seanses_archive и очищает seanses
              (история сеансов сохраняется в архиве; справочники и перехваты не трогаются). Размер файла SQLite
              заметно снизится только если удалить старые данные из архива или вынести архив в отдельный файл; после массовых удалений полезен VACUUM.
            

          

        

        


        

        
Оставить последние N дней (рекомендуется)

        

          Старые сеансы уходят в отдельный файл в data/, из main.sqlite удаляются,
          затем сжимается БД (VACUUM). Перехваты, unit и пользователи не меняются.
        

        

          

            
            
          

          

            
          

        


        
Архив в отдельный файл SQLite (вручную)

        

          Все строки, у которых день в date_time строго раньше выбранной даты (по календарю),
          переносятся в файл в папке data (например seanses_21_04_2026.sqlite), затем удаляются из main.sqlite.
          Справочники и перехваты не затрагиваются.
          По желанию включите VACUUM, чтобы уменьшить размер основной БД после удаления.

              Диагностика базы сеансов
            

            

              Проверка справочника unit на шаблон «частота * и группа *» (из-за него один ID может попадать во все такие радиосети),
              неоднозначные пары частота/группа и фактические пары каналов для выбранного ID в seanses.
            

          

          
        

        

          

            
            
          

          

            
            
          

          

            
            
          

          

            
            
          

          

            
            
          

          

            Календарные сутки — выборка за день первого выхода ID на канале; скользящие часы — от первого выхода на N часов.
            Поле «После ID» работает в обоих режимах: например, 3 — смотреть только первые 3 часа после появления ID (плюс все сеансы до этого момента в окне), чтобы поймать смену ключа без шума до конца суток.
          

        

        
Выберите БД и нажмите «Запустить проверку».

        

        

        

      

    


    

      

        

          

            

              
              Один ID — несколько каналов за день
            

            

              За выбранные календарные сутки в seanses ищутся корреспонденты, у которых есть сеансы на двух и более разных парах «частота + группа»
              (характерно для сбоя парсера, склейки файлов или дубля импорта). Можно сузить до одного ID.
