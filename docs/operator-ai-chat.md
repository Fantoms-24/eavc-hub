# Памятка оператору: AI-чат и оценка EAVC Manager

## Где что находится

| Место | Назначение |
|--------|------------|
| **Модалка «Чат»** → канал **«AI-ассистент»** | Диалог с EAVC Manager (локальная модель Ollama / совместимый API). |

По умолчанию: **Ollama** `http://127.0.0.1:11434`, модель **`qwen2.5:7b-instruct-q3_k_m`**. Настройка в `hub_config.json` / `server_config.json` (блок `"ai"`) или переменные `WEB_PORTAL_AI_MODEL`, `WEB_PORTAL_AI_BASE_URL`. Перед запуском: `ollama list` — модель должна быть в списке.
| **Аналитика** → блок AI (сводка смены / отчёт за период) | Длинные отчёты по перехватам; **оценка результата** — отдельно от чата (селект + комментарий «для обучения»). |

Оценка **в чате** (под ответом: «да» / «нет») и **в отчёте** пишутся **в разные** таблицы — для датасетов и админки это разные выгрузки.

## Как писать запрос, чтобы чаще попадать в цель

1. **Поиск по тексту** перехватов/сеансов: начните с префикса  
   - `поиск: ваш запрос` или `search: ...` — сразу запускается **широкий** поиск по проекту.  
   - `только перехваты: ...` или `только бланки: ...` — акцент на **перехватах и полнотексте бланков** (к подсказке для маршрутизатора).

2. Уточняйте **«где сказано»**, **«в сеансах, где встречается …»** — это отсекает ответ в виде «сводка межподразделенческих взаимодействий», когда вам нужен именно **текст**.

3. **Массовая замена** подразделения «везде по базе» из чата **не выполняется** — вам ответят объяснением, что сделать вручную или через администратора.

4. **Запись в Unit** (привязка подразделения к **конкретному ID**): явные глаголы вроде «укажи», «запиши для ID …» — не «смени везде».

## Оценки для улучшения модели

- **Да** — ответ реально помог (или честно и ясно отказал).  
- **Нет** — появится **необязательное** поле: коротко, что ожидали (это уходит в датасет и в выгрузку **preference hints**).  
- Отмена в окне комментария = **оценка не отправляется**.

**Админка → AI-агент:** выгрузки `eavc_llm_sft.jsonl` (пары user→assistant) и `eavc_llm_preference_hints.jsonl` (оценка «не полезен» + контекст + при наличии следующая реплика пользователя).
